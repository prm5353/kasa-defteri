# Kasa Defteri

Kişisel gelir-gider, kredi kartı, fiş ve birikim takibi. Telefonda çalışan tek sayfalık bir uygulama.

- Kayıtlar yalnızca kullanıldığı telefonun tarayıcısında (IndexedDB) saklanır; bu depoda kişisel veri yoktur.
- Ekstre, ekran görüntüsü ve fiş okuma için Anthropic API anahtarı uygulamanın Ayarlar ekranına girilir ve sadece cihazda tutulur.
- Yedek almak ve geri yüklemek için Ayarlar → Yedek bölümü kullanılır.

GitHub Pages ile yayınlanır: Settings → Pages → Branch: `main`, klasör: `/ (root)`.
